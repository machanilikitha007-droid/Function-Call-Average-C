# Function Call to Calculate Average

This program uses a function call to calculate the average of three numbers.

## File

average_function.c

## Concepts Used

- Function call
- Function parameters
- Return value
- Arithmetic operation

## How to Run

gcc average_function.c -o average_function
./average_function

## Sample Output

Enter three numbers: 10 20 30
Average = 20.00
